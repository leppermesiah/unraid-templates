# Unraid templates by leppermesiah

Docker templates for [Unraid Community Applications](https://ca.unraid.net/).

| App | What it is | Project |
|---|---|---|
| <img src="https://raw.githubusercontent.com/leppermesiah/letopis/main/public/icon-192.png" width="48"> **Letopis** | Idle civilization simulation: a Stone Age tribe grows into a civilization on its own server while you watch in the browser. | [leppermesiah/letopis](https://github.com/leppermesiah/letopis) |
| <img src="https://raw.githubusercontent.com/leppermesiah/belot/main/icon.png" width="48"> **Belot** | The Bulgarian card game for 4 players, played right in the browser. | [leppermesiah/belot](https://github.com/leppermesiah/belot) |

Install them from the **Apps** tab in Unraid, or add a template by hand from [`templates/`](templates).
Questions and bug reports go to the issues of each app's own repository.
